# ¿Qué es PD Content Studio?

PD Content Studio es el sistema interno de producción de contenido de PD Agencia.
Su objetivo no es generar publicaciones individuales, sino construir una biblioteca de conocimiento reutilizable que permita producir contenido de alta calidad de forma consistente, escalable y documentada.
Cada pieza creada debe fortalecer el sistema.
Nunca dependeremos de la memoria de una conversación o de un único modelo de inteligencia artificial.
El conocimiento pertenece a PD Agencia.

---

# Misión

Diseñar un sistema que permita transformar conocimiento en contenido de alto valor para cualquier canal digital mediante procesos, frameworks, documentación y automatización.

---

# Visión

Convertirse en el núcleo de producción de contenido de PD Agencia, capaz de alimentar múltiples canales, marcas y herramientas de inteligencia artificial sin perder consistencia.

---

# Principios

Todos los activos del proyecto deben respetar los siguientes principios:

- Construimos activos, no respuestas.
- Documentamos antes de recordar.
- La estrategia siempre precede a la ejecución.
- Un sistema vale más que una solución puntual.
- Todo conocimiento importante debe ser reutilizable.
- La IA acelera la producción; las decisiones estratégicas pertenecen a PD Agencia.

# Filosofía de construcción

PD Content Studio se desarrolla como un producto tecnológico.

Cada mejora debe:

- aumentar la reutilización
- reducir la dependencia del conocimiento tácito
- facilitar la automatización
- mejorar la calidad del contenido

# Convenciones

Todo documento del proyecto debe responder como mínimo:

- ¿Por qué existe?
- ¿Qué problema resuelve?
- ¿Cuál es su alcance?
- ¿Cómo debe utilizarse?
- ¿Qué documentos están relacionados?

---

# Contribución

Antes de agregar un nuevo documento verifica:

1. ¿Ya existe uno que resuelva este problema?
2. ¿Es realmente un nuevo activo?
3. ¿Puede reutilizarse?
4. ¿Debe convertirse en un framework?
5. ¿Qué parte del sistema mejora?

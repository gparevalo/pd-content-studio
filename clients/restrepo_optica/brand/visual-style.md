# RESTREPO ÓPTICA — Visual Style

> Guía visual para mantener consistencia en piezas generadas para la marca.

---

# Dirección visual general

La comunicación visual busca transmitir:

- Profesionalismo.
- Confianza.
- Cuidado personal.
- Elegancia.
- Cercanía.

El estilo debe sentirse:

- Limpio.
- Moderno.
- Sofisticado.
- Natural.

Evitar estilos saturados, agresivos o demasiado comerciales.

---

# Fotografía

## Estilo de imágenes

Preferencia por:

- Fotografías de personas reales.
- Retratos naturales.
- Expresiones auténticas.
- Iluminación suave.
- Sensación de bienestar y confianza.

La fotografía debe comunicar:

- Seguridad.
- Naturalidad.
- Cuidado personal.

---

## Composición fotográfica

Preferencias:

- Primeros planos.
- Retratos con espacio negativo.
- Personas como elemento principal.
- Fondos limpios.

Evitar:

- Imágenes genéricas de banco.
- Fotografías demasiado posadas.
- Ambientes visualmente cargados.

---

# Color

## Paleta visual observada

Predominan:

- Tonos beige.
- Nude.
- Arena.
- Blanco.
- Colores suaves y cálidos.

Sensación buscada:

- Premium.
- Calmado.
- Elegante.
- Relacionado con cuidado personal.

---

# Tipografía

## Características observadas

Uso combinado de:

### Tipografía principal

Sans serif limpia:

Características:

- Moderna.
- Fácil lectura.
- Minimalista.

Uso:

- Titulares principales.
- Información educativa.
- Mensajes importantes.

---

### Tipografía secundaria

Tipografía manuscrita / script elegante.

Uso:

- Palabras emocionales.
- Énfasis.
- Conceptos aspiracionales.

Ejemplos:

- belleza
- piel
- cuidado

---

## Reglas tipográficas

Mantener:

- Mucho espacio alrededor del texto.
- Pocas palabras por bloque.
- Jerarquía clara.

Evitar:

- Párrafos largos.
- Demasiadas fuentes combinadas.
- Textos pequeños difíciles de leer.

---

# Composición

Patrones:

- Una idea principal por pieza.
- Texto respirado.
- Elementos centrados o equilibrados.
- Uso importante del espacio vacío.

La imagen tiene protagonismo.

El texto acompaña, no compite.

---

# Estilo de contenido visual

La marca se acerca más a:

✓ Lifestyle premium  
✓ Educación estética  
✓ Cuidado personal  

No se acerca a:

✗ Publicidad agresiva  
✗ Promociones saturadas  
✗ Diseños llenos de elementos

---

# Referencias aplicables

Este estilo puede aplicarse para:

- Educación visual.
- Consejos de cuidado.
- Servicios.
- Bienestar.
- Prevención.

---

# Instrucciones para IA

Cuando generes piezas visuales para RESTREPO ÓPTICA:

1. Prioriza fotografías naturales de alta calidad.
2. Usa fondos limpios.
3. Mantén colores suaves y cálidos.
4. Usa tipografía elegante y legible.
5. Deja espacio negativo.
6. La pieza debe sentirse premium, no promocional.

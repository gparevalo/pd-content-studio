# Post fijo de servicio VICA

## Cuándo usarlo

Para introducir un servicio vigente, explicar una pregunta frecuente o invitar a solicitar información. No funciona como una ficha médica exhaustiva.

## Composición

- **Servicio:** `[Nombre exacto del servicio]` en Playfair Display.
- **Pregunta o beneficio de orientación:** `[Pregunta breve aprobada]`.
- **Apoyo:** `[Explicación de una o dos líneas aprobada]` en Montserrat.
- **Imagen:** recurso real autorizado del tratamiento, equipo o consulta. Si no existe, usar tipografía y composición editorial; no generar una representación engañosa de procedimiento o resultado.
- **CTA:** `Escríbenos por DM` o `096 3681574`.

## Variantes visuales

1. Fondo blanco + foto real a un lado + título en negro/café.
2. Fondo Dark Moss + texto blanco + bloque teal de énfasis.
3. Fondo Ocean Teal + titular blanco + foto o detalle clínico autorizado.

## Copy de apoyo base

`[Servicio] puede ser parte de una valoración personalizada. Para conocer si es adecuado para ti, escríbenos por DM o comunícate al 096 3681574.`

## Control antes de publicar

- Confirmar que el servicio está vigente.
- Confirmar que el texto descriptivo sea el aprobado para esa solicitud.
- Verificar que la imagen corresponda al servicio y no cree expectativas irreales.

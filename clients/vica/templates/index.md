# Plantillas de producción de VICA

> Estas plantillas adaptan el sistema de VICA a formatos repetibles. El tema, información clínica, recursos y aprobación se definen en cada solicitud.

## Uso común

- Formato recomendado: Instagram vertical 4:5 (1080 x 1350 px).
- Titulares: Playfair Display. Información, CTA y datos: Montserrat.
- Paleta: Ocean Teal `#025F61`, Deep Teal `#00898D`, Dark Moss `#4D3B33` y blanco `#FFFFFF`.
- El logo debe mantener su área libre y contraste adecuados.
- El bloque teal sirve para enfatizar una palabra, cifra o frase corta; no para todos los textos.
- La elección de imagen se hace después de aprobar el copy, según la función de cada slide.

## Plantillas disponibles

1. [Carrusel educativo](carousel-educational.md): explicar una duda, mito o concepto.
2. [Carrusel de orientación](carousel-consultation-guidance.md): ayudar a decidir cuándo consultar.
3. [Post fijo de autoridad](static-authority.md): consejo breve con voz profesional.
4. [Post fijo de servicio](static-service.md): presentar un servicio y llevar a contacto.

## Selección de recursos visuales

| Necesidad del contenido | Recurso recomendado |
| --- | --- |
| Transmitir confianza, consulta o cercanía profesional | Foto real autorizada de la Dra. Carrizosa o del espacio clínico. |
| Mostrar un tratamiento, equipo o procedimiento | Foto o video real autorizado; si no existe, diseño tipográfico o imagen editorial no clínica. |
| Explicar una idea abstracta o preventiva | Diseño tipográfico, composición editorial o imagen generada que no haga una promesa médica. |
| Mostrar un resultado, caso o paciente | Solo el recurso específico entregado para la solicitud. |

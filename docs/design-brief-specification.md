# Design Brief Specification

> Este documento define la información mínima necesaria para transformar una solicitud de contenido en una pieza visual ejecutable por diseño.

---

# Propósito

Crear un estándar entre estrategia y diseño para reducir interpretaciones, retrabajos y pérdida de información.

El brief debe permitir que un diseñador pueda comprender:

- Qué debe crear.
- Para quién.
- Con qué objetivo.
- Qué información utilizar.
- Qué restricciones respetar.

---

# Principio

Un diseñador no debería tener que adivinar la intención detrás de una pieza.

El brief debe entregar contexto suficiente para convertir una idea en una ejecución visual.

---

# Estructura del Brief

## 1. Información general

Información básica de seguimiento.

Campos:

```
ID:
Cliente:
Responsable:
Fecha:
Estado:
```

Ejemplo:

```
ID: DES-001
Cliente: Dra. Lore
Estado: En diseño
```

---

# 2. Objetivo del contenido

Define qué debe lograr la pieza.

Ejemplos:

- Educar.
- Generar confianza.
- Convertir.
- Informar.
- Promocionar.
- Recordar.

Pregunta clave:

> ¿Qué queremos que la audiencia haga o entienda después de verlo?

---

# 3. Formato

Define la salida esperada.

Ejemplos:

- Carrusel.
- Post estático.
- Reel.
- Historia.
- Banner.

Debe incluir:

- Dimensiones.
- Cantidad de slides.
- Canal.

Ejemplo:

```
Formato:
Carrusel Instagram

Proporción:
4:5

Cantidad:
7 slides
```

---

# 4. Información de contenido

Aquí se coloca el material aprobado.

Puede incluir:

- Copy entregado.
- Texto del cliente.
- Información técnica.
- Datos importantes.

Regla:

El diseñador no modifica información estratégica sin aprobación.

---

# 5. Estructura narrativa

Cuando aplique, indicar la función de cada parte.

Ejemplo:

```
Slide 1:
Hook

Slide 2:
Problema

Slide 3:
Solución

Slide 4:
Beneficio

Slide 5:
CTA
```

Esto permite que diseño entienda la intención detrás del contenido.

---

# 6. Indicaciones generales

Espacio para restricciones o instrucciones específicas.

Ejemplos:

- No utilizar ciertos elementos.
- Mantener estilo minimalista.
- Utilizar determinada composición.
- Evitar recursos específicos.

---

# 7. Referencias visuales

Material enviado como inspiración.

Puede incluir:

- Pinterest.
- Instagram.
- Competidores.
- Diseños anteriores.

La referencia debe analizarse por:

- Estilo.
- Composición.
- Jerarquía.
- Recursos visuales.

No debe copiarse literalmente.

---

# 8. Recursos disponibles

Archivos necesarios para producción.

Ejemplos:

- Logos.
- Fotografías.
- Videos.
- Fuentes.
- Manual de marca.
- Iconografía.

---

# 9. Revisión y ajustes

Registro del proceso de aprobación.

Incluye:

- Comentarios.
- Cambios solicitados.
- Responsable.
- Estado.

---

# Estados del proceso

Estados recomendados:

```
Pendiente
↓

En diseño
↓

En revisión
↓

Ajustes solicitados
↓

Aprobado
↓

Publicado
```

# Ejemplo convertido desde una solicitud real

## Entrada actual

```
Formato:
Carrusel 4:5

Texto:
¿Qué tipo de lente de contacto es ideal para tu estilo de vida?

Indicaciones:
No colocar estuche cuando se hable de lentes de contacto.
```

---

## Brief estructurado

```
Cliente:
Dra. Lore

Objetivo:
Educar sobre tipos de lentes de contacto.

Formato:
Carrusel Instagram 4:5

Audiencia:
Personas interesadas en lentes de contacto.

Mensaje principal:
Existen diferentes tipos de lentes según necesidades y estilo de vida.

Restricciones:
No utilizar imágenes de estuches de lentes de contacto.

Referencia:
Pendiente de análisis.

Recursos:
Pendiente.
```

---

# Resultado esperado

Un brief completo debe permitir que diseño avance sin necesidad de solicitar nuevamente información básica.

---

- Generación automática de briefs mediante IA.

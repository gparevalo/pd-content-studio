# Glosario

> **El glosario establece el lenguaje oficial de PD Content Studio.**
>
> Todos los documentos, procesos y conversaciones internas deben utilizar estas definiciones para mantener consistencia.

---

# Propósito

Definir un vocabulario común que elimine ambigüedades y facilite la comunicación entre personas, procesos y agentes de IA.

Cuando exista duda sobre el significado de un término, este documento tendrá prioridad.

---

# Términos oficiales

## Workspace

Conjunto de activos permanentes que describen la identidad de un cliente.

## Knowledge

Conocimiento global reutilizable perteneciente a PD Content Studio.

## Production Package

Conjunto de entregables generados por el sistema.

## Production Phase

Cada una de las tres etapas del pipeline:
Ideación,
Producción,
Diseño.



## Activo

Cualquier elemento reutilizable que forme parte de PD Content Studio.

Ejemplos:

- Documento
- Framework
- Plantilla
- Checklist
- Prompt
- Patrón
- Referencia analizada

---

## Brief

Documento o información inicial que describe la necesidad del cliente.

Debe responder qué necesita el cliente y por qué.

---

## Canal

Medio donde será publicado el contenido.

Ejemplos:

- Instagram
- LinkedIn
- Blog
- Newsletter
- Email

---

## CTA (Call To Action)

Acción que esperamos que realice el usuario después de consumir el contenido.

Ejemplos:

- Comentar
- Guardar
- Compartir
- Comprar
- Escribir por WhatsApp

---

## Framework

Estructura reutilizable que organiza una idea para alcanzar un objetivo de comunicación.

Un framework define el "cómo" del contenido.

Ejemplos:

- Storytelling
- Lista
- Mito vs Realidad
- Problema → Solución
- Antes y Después

---

## Output

Resultado final entregado al cliente.

Puede ser:

- Carrusel
- Reel
- Artículo
- Video
- Newsletter
- Landing Page

---

## Patrón

Comportamiento o característica que se repite en múltiples referencias y demuestra ser efectivo.

Los patrones alimentan la creación de frameworks.

---

## Plantilla

Diseño visual reutilizable.

Una plantilla define la estructura gráfica, no el contenido.

---

## Referencia

Material utilizado como fuente de inspiración o análisis.

Puede ser:

- Imagen
- Video
- Carrusel
- Publicación
- Sitio web

Las referencias inspiran.

No se copian.

---

## Sistema

Conjunto de activos, procesos y reglas que permiten producir contenido de forma consistente.

PD Content Studio es un sistema.

---

## Workspace

Espacio de trabajo dedicado a una marca, cliente o proyecto.

Cada Workspace contiene únicamente la información específica de ese contexto.

Ejemplos:

- Identidad de marca
- Audiencia
- Objetivos
- Referencias
- Calendario editorial

Los Workspaces utilizan el conocimiento del Core de PD Content Studio.

---

# Convenciones

## Framework ≠ Plantilla

Un Framework organiza una idea.

Una Plantilla organiza el diseño.

---

## Referencia ≠ Copia

Una referencia sirve para detectar patrones.

Nunca debe replicarse de forma literal.

---

## Output ≠ Activo

El Output se entrega.

El Activo permanece dentro del sistema para generar valor futuro.

---

# Evolución

El glosario es un documento vivo.

Nuevos términos podrán incorporarse cuando:

- Sean reutilizables.
- Eviten ambigüedades.
- Aumenten la claridad del sistema.

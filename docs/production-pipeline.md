# Production Pipeline

> Proceso oficial de producción utilizado por PD Content Studio.

---

# Objetivo

Garantizar que toda publicación siga exactamente el mismo proceso.

---

# Entradas

Toda producción recibe como mínimo:

- Workspace
- Objetivo
- Formato

Opcionalmente:

- Pilar
- Tema
- Copy
- Indicaciones
- Referencias

---

# Fase 1 — Ideación

Objetivo:

Proponer contenido.

Entradas:

- Workspace
- Objetivo
- Pilar
- Referencias

Salida:

- Ideas
- Hooks
- Enfoques

Si existen varias ideas, esperar aprobación antes de continuar.

---

# Fase 2 — Producción

Objetivo:

Construir la publicación.

Generar:

- Copy
- Slides
- Caption
- CTA

Esperar aprobación.

---

# Fase 3 — Diseño

Objetivo:

Transformar el contenido aprobado en una pieza visual.

Generar:

- Dirección visual
- Prompts de imágenes
- PPTX editable
- Recursos

---

# Output

Production Package.

---

# Regla principal

Nunca avanzar a la siguiente fase sin la aprobación de la fase anterior.

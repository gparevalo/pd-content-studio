# Reference Analysis

> Este documento define cómo PD Content Studio analiza referencias para convertirlas en conocimiento reutilizable.

---

# Objetivo

Las referencias no se utilizan para copiar contenido.

Se utilizan para identificar patrones que puedan aplicarse respetando la identidad de cada cliente.

---

# Tipos de referencias

## Inspiración

Contenido encontrado en Pinterest, Instagram, Behance u otras fuentes.

Objetivo:

Extraer ideas.

---

## Publicaciones anteriores

Contenido ya publicado por el cliente.

Objetivo:

Mantener consistencia y evitar repeticiones.

---

## Referencias solicitadas

Material enviado por el cliente.

Objetivo:

Comprender expectativas.

---

# Qué analizar

Cada referencia debe analizarse desde varias dimensiones.

## Contenido

- Tema
- Objetivo
- Tipo de publicación
- CTA

---

## Copy

- Hook
- Longitud
- Estructura
- Lenguaje

---

## Diseño

- Jerarquía visual
- Espaciado
- Fotografía
- Uso del color
- Tipografía

---

## Engagement

Cuando sea posible:

- Comentarios
- Compartidos
- Guardados

---

# Resultado del análisis

Nunca copiar.

Siempre responder:

- ¿Qué funciona?
- ¿Por qué funciona?
- ¿Qué patrón podemos reutilizar?
- ¿Cómo adaptarlo al Workspace?

---

# Principios

- Analizar.
- Aprender.
- Adaptar.

Nunca replicar.
